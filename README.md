# Admin Panel

A modern and responsive Admin Dashboard built to manage users, monitor analytics, and control application resources efficiently.
📌 Features
- 🔐 Secure Admin Authentication
- 👥 User Management
- 📊 Dashboard Analytics
- 📝 Content Management
- 📂 Category & Resource Management
- 🔍 Search & Filtering
- 📱 Responsive Design
- 🌙 Light/Dark Mode (Optional)
- 📈 Charts & Reports
- ⚡ Fast and Optimized Performance

🛠️ Tech Stack
Frontend
- React.js
- Vite
- Tailwind CSS
- React Router
- Axios

Backend
- Node.js
- Express.js

Database
- MongoDB
- Mongoose

Authentication
- JWT (JSON Web Token)
- bcrypt

🔒 Authentication
The admin panel uses JWT-based authentication.
Workflow:
1. Admin Login
2. JWT Token Generated
3. Token Stored Securely
4. Protected Routes
5. Logout Clears Session
